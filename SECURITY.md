# Security Policy

## Supported versions

Only the latest release of this plugin is supported.

## Reporting a vulnerability

Please report security issues privately:

- [GitHub Security Advisories](https://github.com/Kestral-Team/kestral-plugins/security/advisories/new) on this repository
- Email [support@kestral.team](mailto:support@kestral.team) with subject `Security: kestral-plugins`

Please do not open public GitHub issues for vulnerabilities.
