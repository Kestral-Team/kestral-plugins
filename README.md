# Kestral Plugins

Official plugins for [Kestral](https://app.kestral.ai) — AI-powered project management.

## Install

### Claude Code

```bash
/plugin marketplace add Kestral-Team/kestral-plugins
/plugin install kestral@kestral-plugins
```

### Codex CLI

```bash
codex plugin marketplace add Kestral-Team/kestral-plugins
codex plugin install kestral@kestral-plugins
```

## Included plugins

| Plugin | Description |
| --- | --- |
| **kestral-onboarding** | Onboard a project to Kestral from a folder of docs, in one chat command. Run `/kestral:init` to get started. |
